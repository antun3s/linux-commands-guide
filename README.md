# Sobre Este Repositório

Este repositório é uma versão editada do projeto original Quartz v4, adaptada para hospedar a página disponível em: [https://linux-commands.antunes.pro/](https://linux-commands.antunes.pro/).

## Sobre o Quartz v4
> “[One] who works with the door open gets all kinds of interruptions, but [they] also occasionally gets clues as to what the world is and what might be important.” — Richard Hamming

Quartz é um conjunto de ferramentas que ajuda você a publicar seu [jardim digital](https://jzhao.xyz/posts/networked-thought) e notas como um site de forma gratuita.

Quartz v4 apresenta uma reescrita completa, focando na extensibilidade e facilidade de uso para o usuário final.

🔗 Leia a documentação e comece: https://quartz.jzhao.xyz/
