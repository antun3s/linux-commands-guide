# Comando `cat`

O comando **`cat`** (Concatenate) é usado para exibir o conteúdo de arquivos no terminal.

## Sintaxe básica
    cat [arquivo]

## Exemplos
- **Exibir o conteúdo de um arquivo**:
      cat arquivo.txt

- **Concatenar múltiplos arquivos**:
      cat arquivo1.txt arquivo2.txt

- **Exibir o conteúdo com numeração de linhas**:
      cat -n arquivo.txt
