# Comando `tail`

O comando **`tail`** é usado para exibir as últimas linhas de um arquivo.

## Sintaxe básica
    tail [opções] [arquivo]

## Exemplos
- **Exibir as últimas 10 linhas de um arquivo**:
      tail arquivo.txt

- **Exibir as últimas N linhas**:
      tail -n 20 arquivo.txt

- **Acompanhar novas linhas em tempo real**:
      tail -f arquivo.log
