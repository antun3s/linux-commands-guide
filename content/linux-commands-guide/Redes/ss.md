# Comando `ss`

O comando **`ss`** (Socket Statistics) é uma ferramenta moderna para exibir informações sobre conexões de rede.

## Sintaxe básica
    ss [opções]

## Exemplos
- **Exibir todas as conexões**:
      ss -a

- **Exibir conexões TCP**:
      ss -t

- **Exibir conexões UDP**:
      ss -u
