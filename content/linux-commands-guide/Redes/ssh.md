# Comando `ssh`

O comando **`ssh`** (Secure Shell) é usado para conectar-se a um servidor remoto de forma segura.

## Sintaxe básica
    ssh [usuário]@[host]

## Exemplos
- **Conectar a um servidor remoto**:
      ssh usuario@192.168.1.1

- **Especificar uma porta**:
      ssh -p 2222 usuario@192.168.1.1
