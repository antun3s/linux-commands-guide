# Comando `ping`

O comando **`ping`** é usado para testar a conectividade entre dois dispositivos em uma rede.

## Sintaxe básica
    ping [opções] [endereço]

## Exemplos
- **Testar conectividade com um endereço IP**:
      ping 192.168.1.1

- **Definir o número de pacotes**:
      ping -c 4 google.com

- **Intervalo entre pacotes**:
      ping -i 2 google.com
