# Comando `alias`

O comando **`alias`** é usado para criar atalhos para comandos.

## Sintaxe básica
    alias [nome]='[comando]'

## Exemplos
- **Criar um alias**:
      alias ll='ls -la'

- **Listar aliases existentes**:
      alias

- **Remover um alias**:
      unalias ll
