# Comando `df`

O comando **`df`** (Disk Free) exibe o espaço livre em discos e sistemas de arquivos.

## Sintaxe básica
    df [opções] [dispositivo]

## Exemplos
- **Exibir espaço livre**:
      df

- **Exibir em formato legível**:
      df -h

- **Exibir sistemas de arquivos específicos**:
      df -t ext4
