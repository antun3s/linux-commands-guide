# Comando `wget`

O comando **`wget`** é usado para baixar arquivos da web.

## Sintaxe básica
    wget [opções] [URL]

## Exemplos
- **Baixar um arquivo**:
      wget https://exemplo.com/arquivo.txt

- **Baixar recursivamente**:
      wget -r https://exemplo.com

- **Continuar um download interrompido**:
      wget -c https://exemplo.com/arquivo.txt
