# Comando `echo`

O comando **`echo`** exibe mensagens no terminal.

## Sintaxe básica
    echo [mensagem]

## Exemplos
- **Exibir uma mensagem**:
      echo "Olá, mundo!"

- **Exibir o valor de uma variável**:
      echo $HOME

- **Adicionar texto a um arquivo**:
      echo "texto" >> arquivo.txt
