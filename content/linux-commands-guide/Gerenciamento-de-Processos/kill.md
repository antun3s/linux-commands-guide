# Comando `kill`

O comando **`kill`** é usado para encerrar processos.

## Sintaxe básica
    kill [opções] [PID]

## Exemplos
- **Encerrar um processo**:
      kill 1234

- **Forçar o encerramento**:
      kill -9 1234
