# Comando `chmod`

O comando **`chmod`** (Change Mode) é usado para alterar permissões de arquivos e diretórios.

## Sintaxe básica
    chmod [opções] [modo] [arquivo/diretório]

## Exemplos
- **Dar permissão de leitura para todos**:
      chmod a+r arquivo.txt

- **Dar permissão de execução para o dono**:
      chmod u+x script.sh

- **Definir permissões numéricas**:
      chmod 755 arquivo.txt
