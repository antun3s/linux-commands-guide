# Comando `rmdir`

O comando **`rmdir`** (Remove Directory) é usado para remover diretórios vazios.

## Sintaxe básica
    rmdir [opções] [diretório]

## Exemplos
- **Remover um diretório vazio**:
      rmdir diretorio_vazio

- **Remover múltiplos diretórios**:
      rmdir dir1 dir2 dir3
