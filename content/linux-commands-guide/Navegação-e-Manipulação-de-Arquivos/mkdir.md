# Comando `mkdir`

O comando **`mkdir`** (Make Directory) é usado para criar diretórios.

## Sintaxe básica
    mkdir [opções] [diretório]

## Exemplos
- **Criar um diretório**:
      mkdir novo_diretorio

- **Criar diretórios com subdiretórios**:
      mkdir -p dir1/dir2/dir3
