# Comando `pwd`

O comando **`pwd`** (Print Working Directory) exibe o diretório atual.

## Sintaxe básica
    pwd

## Exemplos
- **Exibir o diretório atual**:
      pwd

## Links Relacionados
- [[cd]]: Navega entre diretórios.
- [[ls]]: Lista os arquivos de um diretório.
