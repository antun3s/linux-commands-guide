# Comando `touch`

O comando **`touch`** é usado para criar arquivos vazios ou atualizar timestamps.

## Sintaxe básica
    touch [opções] [arquivo]

## Exemplos
- **Criar um arquivo vazio**:
      touch arquivo.txt

- **Atualizar timestamp**:
      touch -c arquivo.txt
