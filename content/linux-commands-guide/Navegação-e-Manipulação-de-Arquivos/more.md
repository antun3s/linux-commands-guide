# Comando `more`

O comando **`more`** é usado para exibir o conteúdo de arquivos de forma paginada.

## Sintaxe básica
    more [arquivo]

## Exemplos
- **Exibir o conteúdo de um arquivo**:
      more arquivo.txt

- **Navegar no arquivo**:
  - **Avançar**: `Espaço`
  - **Sair**: `q`
