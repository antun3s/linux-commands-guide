# Comando `cd`

O comando **`cd`** (Change Directory) é usado para navegar entre diretórios no Linux.

## Sintaxe básica
    cd [diretório]

## Exemplos
- **Ir para o diretório home**:
      cd ~

- **Voltar um diretório**:
      cd ..

- **Ir para um diretório específico**:
      cd /caminho/do/diretorio
