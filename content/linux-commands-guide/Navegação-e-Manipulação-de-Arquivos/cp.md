# Comando `cp`

O comando **`cp`** (Copy) é usado para copiar arquivos e diretórios.

## Sintaxe básica
    cp [opções] [origem] [destino]

## Exemplos
- **Copiar um arquivo**:
      cp arquivo.txt backup/

- **Copiar um diretório**:
      cp -r diretorio/ backup/

- **Copiar preservando atributos**:
      cp -p arquivo.txt backup/
